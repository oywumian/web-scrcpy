# Web Scrcpy 共享控制台

这是一个面向局域网共享控制的网页版 Android 控制台。

## 适合的使用方式

这套项目当前最适合放在一台 Windows 电脑上运行：

- 电脑负责连接 Android 手机
- 局域网里的其他电脑、平板或手机浏览器访问这台电脑
- 所有人看到的是同一台手机画面

## 启动局域网服务

先确保已经完成依赖安装，并且项目已经构建过。

直接双击下面这个文件即可启动：

- `start-lan.cmd`

启动后会打开一个本地控制台窗口，服务会持续运行。不要关闭这个窗口，关闭后网页服务也会停止。

## 停止局域网服务

直接双击下面这个文件即可停止：

- `stop-lan.cmd`

## 局域网访问地址

服务启动后：

- 本机访问 `http://127.0.0.1:4173`
- 局域网设备访问 `http://你的电脑局域网IP:4173`

Windows 上可以先执行 `ipconfig`，查看当前联网网卡对应的 IPv4 地址。

## 注意事项

- 手机需要打开 USB 调试
- 手机第一次连接时要确认调试授权
- 如果 Windows 弹出防火墙提示，请允许当前服务访问专用网络
- 如果网页能打开但没有设备，先检查数据线、USB 调试授权和 ADB 连接状态

## 常用文件

- `server.mjs`：局域网服务和控制后端
- `src/App.tsx`：前端主界面
- `src/App.css`：前端样式
- `start-lan.cmd`：启动局域网服务
- `stop-lan.cmd`：停止局域网服务
